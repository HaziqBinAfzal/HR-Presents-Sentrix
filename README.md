# Sentrix

Sentrix is an AI-assisted Python project analysis platform maintained by HR-Presents.

It helps users upload Python projects, run code-quality and security analysis, review AI-generated recommendations, inspect historical results, and download or export reports.

## Core capabilities

- User registration, login, profiles, and settings
- Python project upload and workspace management
- Syntax, linting, formatting, security, and complexity analysis
- AI summaries and remediation recommendations
- Dashboard metrics and project history
- User reviews and contact support workflow
- Secure report downloads and CSV/JSON exports

## Local setup

1. Create and activate a Python virtual environment.
2. Install the dependencies listed in `requirements.txt`.
3. Copy `.env.example` to `.env` and configure the required values.
4. Run `python app.py`.

The application uses environment-based configuration and stores local development data under the configured instance and upload directories.
