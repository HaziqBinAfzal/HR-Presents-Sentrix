One Integrated Analysis Engine

No user-supplied API key is required. Sentrix automatically coordinates its analysis tools.

Code Quality

Security

Complexity

Formatting

Black evaluates consistent formatting as part of the overall quality workflow.

Built with proven Python technologies

Sentrix preserves its Flask and Bootstrap architecture while using Pylint, Bandit, Radon, Black, AST, tokenize, and pathlib for integrated project analysis.
